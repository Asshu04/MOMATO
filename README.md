# MOMATO 🍔

MOMATO is a food delivery platform currently being developed using Python, FastAPI, SQL Server, and SQLAlchemy.

The project is being built as a practical full-stack application to understand how a real-world food delivery system works, from backend APIs and database design to authentication, cart management, and eventually a React frontend.

---

## 🚀 Project Status

MOMATO is currently in **backend development**.

### Completed

- FastAPI backend setup
- SQL Server database connection

- Restaurant CRUD APIs
- Food CRUD APIs
- User registration
- Password hashing with bcrypt

- JWT authentication
- Protected user profile API
